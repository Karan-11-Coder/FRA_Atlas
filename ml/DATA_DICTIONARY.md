# `ml/data/labeled_dataset.csv` — data dictionary

1540 synthetic training plots across 7 districts in Madhya Pradesh, Odisha,
Telangana, and Tripura. Each row is one sampled coordinate with real
(SoilGrids/open-elevation) or static-reference (groundwater/rainfall/
Scheduled Area) features, plus 6 rule-derived scheme-suitability scores
used as training labels.

This file is a copy of the repo-root `labeled_dataset.csv` with one column
dropped — see the note on `distance_to_water_km` below. The repo-root copy
keeps the original column (as an all-null placeholder) for provenance.

## Identity / geography

| Column | dtype | Meaning | Caveats |
|---|---|---|---|
| `plot_id` | string | Synthetic plot identifier, `SYN-00001` … `SYN-01540` | Should be unique — see sanity report |
| `state` | string | One of the 4 target states | |
| `district` | string | One of the 7 sampled districts | |
| `lat`, `lon` | float | Coordinates the plot's features were fetched for | Sampled inside real district boundary polygons, not real claim locations |

## Claim-record fields (not fetched — assigned when the synthetic dataset was built)

| Column | dtype | Meaning | Caveats |
|---|---|---|---|
| `land_area_ha` | float | Land area in hectares | Randomly sampled in [0.2, 4.0] ha |
| `claim_type` | string | `IFR`, `CR`, or `CFR` | Randomly assigned (55%/20%/25% weights) |

## Soil / elevation features — real API data, partly imputed

| Column | dtype | Meaning | Caveats |
|---|---|---|---|
| `soil_ph` | float | Soil pH, 0-5cm depth (ISRIC SoilGrids) | ~29% of rows are **not** a real per-point reading — see imputation note below |
| `soil_organic_carbon` | float | Soil organic carbon, 0-5cm depth (ISRIC SoilGrids) | Same caveat as `soil_ph` |
| `soil_clay_pct` | float | Soil clay %, 0-5cm depth (ISRIC SoilGrids) | Same caveat as `soil_ph` |
| `elevation_m` | float | Elevation in meters (open-elevation) | ~25% of rows are **not** a real per-point reading — same caveat, own imputation flag |
| `soil_ph_imputed` | bool | `True` if `soil_ph` is a district-mean estimate, not a real SoilGrids reading | |
| `soil_organic_carbon_imputed` | bool | Same, for `soil_organic_carbon` | |
| `soil_clay_pct_imputed` | bool | Same, for `soil_clay_pct` | |
| `elevation_m_imputed` | bool | Same, for `elevation_m` | |

**Imputation note (important, read before EDA):** the original live-fetch build had ~25-29% failures on these four fields, almost certainly from SoilGrids/open-elevation rate-limiting. A real re-fetch pass was attempted for the missing rows but abandoned after 2.5+ hours with no completion in sight (the API was responding extremely slowly that day — requests that took 1-4s early in the run were taking 60+ seconds each by the end, well past the retry/timeout budget being worth the wait). Instead, every still-missing cell was filled with the **(state, district) mean of the real values from other rows in the same district** — a real statistical estimate from real neighboring data, not a fabricated number, but also not a real per-point measurement. All 7 districts had enough real data to compute a genuine district mean for all four fields (no row fell back to the dataset-wide mean). Every imputed cell is marked `True` in its corresponding `*_imputed` column — **filter on these before treating `soil_ph`/`elevation_m` etc. as ground truth**, and consider comparing model performance with vs. without the imputed rows once training starts.

## Static reference-table features

| Column | dtype | Meaning | Caveats |
|---|---|---|---|
| `groundwater_stress_pct` | float | District-level groundwater stress % (CGWB-style category, static lookup table) | Regional estimate, not a live per-point measurement — see `backend/services/reference_datasheets.py` |
| `rainfall_mm_avg` | float | District-level average annual rainfall in mm (static lookup table) | One data point (Chhindwara) verified against a real published source; the rest are estimated from regional climatology, not yet cross-checked against exact IMD district reports |
| `is_scheduled_area` | bool | Whether the state has Fifth/Sixth Schedule constitutional status | Real, verified constitutional fact — MP/Odisha/Telangana are Fifth Schedule, Tripura is Sixth Schedule, collapsed to a single boolean for v1 |

## Excluded from this copy

`distance_to_water_km` — dropped from `ml/data/labeled_dataset.csv` because it is 100% null for every row: no water-body geometry file has been sourced yet, so nothing computes it (a known, already-documented gap, not something this session's backfill touches). The repo-root `labeled_dataset.csv` keeps the empty column for provenance; this copy doesn't, so it isn't sitting there as a column of nothing for EDA to puzzle over.

## Scheme-score label columns (0–100, rule-derived training targets)

All six were generated by `backend/services/scheme_rules.py`, sourced from real scheme criteria and adjacent government indices where possible. Full per-scheme sourcing, tiering, and reasoning is in `FRA_Atlas_Scoring_Methodology_Note.md` — **that file doesn't currently exist anywhere in this repo** (checked, not present), so treat the summary below as the interim reference until it's supplied; don't take it as the full sourcing record.

**These are rule-derived labels for training a future model, not real historical scheme-allocation outcomes or official eligibility determinations.**

| Column | Shape | What it represents |
|---|---|---|
| `pm_kisan_score` | Near-binary gate | Clusters tightly around two means (~85 for IFR claims, ~22 for CR/CFR) — models PM-KISAN's real eligibility structure, which is close to a yes/no gate, not a graded score |
| `mgnrega_score` | Near-binary gate, narrower band | MGNREGA is a universal household entitlement — this column models *work-priority relevance* (driven by groundwater stress category + Scheduled Area status), not "who qualifies" |
| `jjm_score` | Explicitly low-confidence / wide-noise proxy | JJM prioritizes at habitation level in reality, not per-plot — this is a deliberately weak, wider-noise proxy standing in for something the scheme doesn't actually score this granularly |
| `pmfby_score` | Explicitly low-confidence / wide-noise proxy | Similar caveat — driven mostly by rainfall deviation from a regional norm, not PMFBY's real (much more localized, crop-specific) risk assessment |
| `pmksy_score` | Genuinely continuous, multi-factor | Weighted composite (groundwater, rainfall, Scheduled Area, land area, claim type, soil) modeled on the real IWMP/PMKSY-Watershed 150-point prioritization matrix — the most defensible of the six |
| `soil_health_card_score` | Genuinely continuous, multi-factor | Driven by real Soil Health Card official pH/organic-carbon bands — the other genuinely graded score, varies smoothly with each plot's actual soil chemistry |

Each score has independent Gaussian noise added (σ 4–6 depending on scheme) before clipping to [0, 100], so no two plots with identical inputs will show bit-identical scores.
